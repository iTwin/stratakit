This guide provides the necessary steps for migrating from [iTwinUI](https://itwinui.bentley.com/) to StrataKit.

:::note
Migration to StrataKit can be done gradually, since iTwinUI can coexist in the same application by utilizing the [StrataKit theme bridge](https://github.com/iTwin/iTwinUI/wiki/StrataKit-theme-bridge).
:::

## Migration steps

<Steps>

1. **Set up StrataKit**

   Follow the [set up StrataKit guide](/getting-started/develop/) to install the necessary dependencies and set up your project.

2. **Enable the StrataKit theme bridge**

   Pass the StrataKit [**Root**](/components/root) into the `as` prop of the iTwinUI [**ThemeProvider**](https://itwinui.bentley.com/docs/themeprovider) to render a single DOM element.

   ```diff
    <ThemeProvider
      theme={theme}
   +  as={Root}
    >
      {/* … */}
    </ThemeProvider>
   ```

   Specify the `Root` props directly on the `ThemeProvider` component.

   ```diff
    <ThemeProvider
      theme={theme}
      as={Root}
   +  colorScheme={theme}
    >
      {/* … */}
    </ThemeProvider>
   ```

   Finally, activate the `themeBridge` future flag.

   ```diff
    <ThemeProvider
      theme={theme}
      as={Root}
      colorScheme={theme}
   +  future={{ themeBridge: true }} // or future={true}
    >
      {/* … */}
    </ThemeProvider>
   ```

   :::note
   If StrataKit's accent color is not compatible with your existing UI, see [visual transition](#visual-transition).
   :::

3. **Replace `@itwin/itwinui-icons-react` with `@stratakit/icons`**

   Replace the usage of iTwinUI icons from `@itwin/itwinui-icons-react` with their StrataKit counterparts. Refer to the [use StrataKit icons](#use-stratakit-icons) section below for the full icon mapping.

   ```diff
   - import { SvgAdd } from '@itwin/itwinui-icons-react';
   - <SvgAdd />

   + import { Icon } from "@stratakit/mui";
   + import { svgAdd } from "@stratakit/icons/add";
   + <Icon href={svgAdd} />
   ```

   Once all usage of `@itwin/itwinui-icons-react` has been replaced, it is safe to remove the dependency.

   ```console
   npm uninstall @itwin/itwinui-icons-react
   ```

4. **Replace usage of `@itwin/itwinui-react`**

   Replace the usage of components from `@itwin/itwinui-react` with their [StrataKit counterparts](/components/overview/). Some components are provided by `@mui/material`, while others live in `@stratakit/structures`.

   Once all usage of `@itwin/itwinui-react` has been replaced, it is safe to remove the dependency.

   ```console
   npm uninstall @itwin/itwinui-react
   ```

</Steps>

## Visual transition

By default, StrataKit uses its preferred **"aurora"** green [accent color](/components/root/#accent-color). Some legacy applications rely on a blue accent color, especially when parts of the UI are not implemented with up-to-date iTwinUI components. In these cases, the aurora accent color can clash with the existing UI or require significant adjustments to it.

To ease the visual transition, use StrataKit's **"cobalt"** accent color, which is designed for better compatibility with iTwinUI's color palette. Set the `unstable_accentColor` prop on the [**Root**](/components/root) component to apply the accent color to all StrataKit components.

```diff
 <ThemeProvider
   theme={theme}
   as={Root}
   colorScheme={theme}
   future={true}
+  unstable_accentColor="cobalt"
 >
   {/* … */}
 </ThemeProvider>
```

Once the visual transition is complete, remove the `unstable_accentColor` prop to continue using StrataKit's preferred accent color.
