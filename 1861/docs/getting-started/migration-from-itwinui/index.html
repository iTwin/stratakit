Migrating from iTwinUI

Learn how to migrate from iTwinUI to StrataKit

This guide provides the necessary steps for migrating from iTwinUI to StrataKit.

Note

Migration to StrataKit can be done gradually, since iTwinUI can coexist in the same application by utilizing the StrataKit theme bridge.

Migration steps

Section titled “Migration steps”

  1. Set up StrataKit

    Follow the set up StrataKit guide to install the necessary dependencies and set up your project.

  2. Enable the StrataKit theme bridge

    Pass the StrataKit Root into the as prop of the iTwinUI ThemeProvider to render a single DOM element.

    Specify the Root props directly on the ThemeProvider component.

    Finally, activate the themeBridge future flag.

    Note

    If StrataKit’s accent color is not compatible with your existing UI, see visual transition.

  3. Replace @itwin/itwinui-icons-react with @stratakit/icons

    Replace the usage of iTwinUI icons from @itwin/itwinui-icons-react with their StrataKit counterparts. Refer to the use StrataKit icons section below for the full icon mapping.

    Once all usage of @itwin/itwinui-icons-react has been replaced, it is safe to remove the dependency.

  4. Replace usage of @itwin/itwinui-react

    Replace the usage of components from @itwin/itwinui-react with their StrataKit counterparts. Some components are provided by @mui/material, while others live in @stratakit/structures.

    Once all usage of @itwin/itwinui-react has been replaced, it is safe to remove the dependency.

Visual transition

Section titled “Visual transition”

By default, StrataKit uses its preferred “aurora” green accent color. Some legacy applications rely on a blue accent color, especially when parts of the UI are not implemented with up-to-date iTwinUI components. In these cases, the aurora accent color can clash with the existing UI or require significant adjustments to it.

To ease the visual transition, use StrataKit’s “cobalt” accent color, which is designed for better compatibility with iTwinUI’s color palette. Set the unstable_accentColor prop on the Root component to apply the accent color to all StrataKit components.

Once the visual transition is complete, remove the unstable_accentColor prop to continue using StrataKit’s preferred accent color.
