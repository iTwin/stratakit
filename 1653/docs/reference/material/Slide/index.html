Slide API

Component status:
stable

Import

Section titled “Import”

Slide.Slide

Section titled “Slide.Slide”

children

Section titled “children”
Type: ReactElement<unknown, any> (required)

A single child content element.

about

Section titled “about”
Type: string | undefined (optional)

accessKey

Section titled “accessKey”
Type: string | undefined (optional)

addEndListener

Section titled “addEndListener”
Type: ((node: HTMLElement, done: () => void) => void) | undefined (optional)

Add a custom transition end trigger. Called with the transitioning DOM node and a done callback. Allows for more fine grained transition end logic. Note: Timeouts are still used as a fallback if provided.

appear

Section titled “appear”
Type: boolean | undefined (optional)
Default: true

Perform the enter transition when it first mounts if in is also true. Set this to false to disable this behavior.

aria-activedescendant

Section titled “aria-activedescendant”
Type: string | undefined (optional)

Identifies the currently active element when DOM focus is on a composite widget, textbox, group, or application.

aria-atomic

Section titled “aria-atomic”
Type: Booleanish | undefined (optional)

Indicates whether assistive technologies will present all, or only parts of, the changed region based on the change notifications defined by the aria-relevant attribute.

aria-autocomplete

Section titled “aria-autocomplete”
Type: "none" | "list" | "inline" | "both" | undefined (optional)

Indicates whether inputting text could trigger display of one or more predictions of the user’s intended value for an input and specifies how predictions would be presented if they are made.

aria-braillelabel

Section titled “aria-braillelabel”
Type: string | undefined (optional)

Indicates an element is being modified and that assistive technologies MAY want to wait until the modifications are complete before exposing them to the user.

aria-brailleroledescription

Section titled “aria-brailleroledescription”
Type: string | undefined (optional)

Defines a human-readable, author-localized abbreviated description for the role of an element, which is intended to be converted into Braille.

aria-busy

Section titled “aria-busy”
Type: Booleanish | undefined (optional)

aria-checked

Section titled “aria-checked”
Type: boolean | "true" | "false" | "mixed" | undefined (optional)

Indicates the current “checked” state of checkboxes, radio buttons, and other widgets.

aria-colcount

Section titled “aria-colcount”
Type: number | undefined (optional)

Defines the total number of columns in a table, grid, or treegrid.

aria-colindex

Section titled “aria-colindex”
Type: number | undefined (optional)

Defines an element’s column index or position with respect to the total number of columns within a table, grid, or treegrid.

aria-colindextext

Section titled “aria-colindextext”
Type: string | undefined (optional)

Defines a human readable text alternative of aria-colindex.

aria-colspan

Section titled “aria-colspan”
Type: number | undefined (optional)

Defines the number of columns spanned by a cell or gridcell within a table, grid, or treegrid.

aria-controls

Section titled “aria-controls”
Type: string | undefined (optional)

Identifies the element (or elements) whose contents or presence are controlled by the current element.

aria-current

Section titled “aria-current”
Type: boolean | "true" | "false" | "page" | "step" | "location" | "date" | "time" | undefined (optional)

Indicates the element that represents the current item within a container or set of related elements.

aria-describedby

Section titled “aria-describedby”
Type: string | undefined (optional)

Identifies the element (or elements) that describes the object.

aria-description

Section titled “aria-description”
Type: string | undefined (optional)

Defines a string value that describes or annotates the current element.

aria-details

Section titled “aria-details”
Type: string | undefined (optional)

Identifies the element that provides a detailed, extended description for the object.

aria-disabled

Section titled “aria-disabled”
Type: Booleanish | undefined (optional)

Indicates that the element is perceivable but disabled, so it is not editable or otherwise operable.

aria-dropeffect Deprecated

Section titled “aria-dropeffect Deprecated ”

Caution

in ARIA 1.1
Type: "none" | "link" | "copy" | "execute" | "move" | "popup" | undefined (optional)

Indicates what functions can be performed when a dragged object is released on the drop target.

aria-errormessage

Section titled “aria-errormessage”
Type: string | undefined (optional)

Identifies the element that provides an error message for the object.

aria-expanded

Section titled “aria-expanded”
Type: Booleanish | undefined (optional)

Indicates whether the element, or another grouping element it controls, is currently expanded or collapsed.

aria-flowto

Section titled “aria-flowto”
Type: string | undefined (optional)

Identifies the next element (or elements) in an alternate reading order of content which, at the user’s discretion, allows assistive technology to override the general default of reading in document source order.

aria-grabbed Deprecated

Section titled “aria-grabbed Deprecated ”

Caution

in ARIA 1.1
Type: Booleanish | undefined (optional)

Indicates an element’s “grabbed” state in a drag-and-drop operation.

aria-haspopup

Section titled “aria-haspopup”
Type: boolean | "true" | "false" | "dialog" | "grid" | "listbox" | "menu" | "tree" | undefined (optional)

Indicates the availability and type of interactive popup element, such as menu or dialog, that can be triggered by an element.

aria-hidden

Section titled “aria-hidden”
Type: Booleanish | undefined (optional)

Indicates whether the element is exposed to an accessibility API.

aria-invalid

Section titled “aria-invalid”
Type: boolean | "true" | "false" | "grammar" | "spelling" | undefined (optional)

Indicates the entered value does not conform to the format expected by the application.

aria-keyshortcuts

Section titled “aria-keyshortcuts”
Type: string | undefined (optional)

Indicates keyboard shortcuts that an author has implemented to activate or give focus to an element.

aria-label

Section titled “aria-label”
Type: string | undefined (optional)

Defines a string value that labels the current element.

aria-labelledby

Section titled “aria-labelledby”
Type: string | undefined (optional)

Identifies the element (or elements) that labels the current element.

aria-level

Section titled “aria-level”
Type: number | undefined (optional)

Defines the hierarchical level of an element within a structure.

aria-live

Section titled “aria-live”
Type: "off" | "assertive" | "polite" | undefined (optional)

Indicates that an element will be updated, and describes the types of updates the user agents, assistive technologies, and user can expect from the live region.

aria-modal

Section titled “aria-modal”
Type: Booleanish | undefined (optional)

Indicates whether an element is modal when displayed.

aria-multiline

Section titled “aria-multiline”
Type: Booleanish | undefined (optional)

Indicates whether a text box accepts multiple lines of input or only a single line.

aria-multiselectable

Section titled “aria-multiselectable”
Type: Booleanish | undefined (optional)

Indicates that the user may select more than one item from the current selectable descendants.

aria-orientation

Section titled “aria-orientation”
Type: "horizontal" | "vertical" | undefined (optional)

Indicates whether the element’s orientation is horizontal, vertical, or unknown/ambiguous.

aria-owns

Section titled “aria-owns”
Type: string | undefined (optional)

Identifies an element (or elements) in order to define a visual, functional, or contextual parent/child relationship between DOM elements where the DOM hierarchy cannot be used to represent the relationship.

aria-placeholder

Section titled “aria-placeholder”
Type: string | undefined (optional)

Defines a short hint (a word or short phrase) intended to aid the user with data entry when the control has no value. A hint could be a sample value or a brief description of the expected format.

aria-posinset

Section titled “aria-posinset”
Type: number | undefined (optional)

Defines an element’s number or position in the current set of listitems or treeitems. Not required if all elements in the set are present in the DOM.

aria-pressed

Section titled “aria-pressed”
Type: boolean | "true" | "false" | "mixed" | undefined (optional)

Indicates the current “pressed” state of toggle buttons.

aria-readonly

Section titled “aria-readonly”
Type: Booleanish | undefined (optional)

Indicates that the element is not editable, but is otherwise operable.

aria-relevant

Section titled “aria-relevant”
Type: "text" | "additions" | "additions removals" | "additions text" | "all" | "removals" | "removals additions" | "removals text" | "text additions" | "text removals" | undefined (optional)

Indicates what notifications the user agent will trigger when the accessibility tree within a live region is modified.

aria-required

Section titled “aria-required”
Type: Booleanish | undefined (optional)

Indicates that user input is required on the element before a form may be submitted.

aria-roledescription

Section titled “aria-roledescription”
Type: string | undefined (optional)

Defines a human-readable, author-localized description for the role of an element.

aria-rowcount

Section titled “aria-rowcount”
Type: number | undefined (optional)

Defines the total number of rows in a table, grid, or treegrid.

aria-rowindex

Section titled “aria-rowindex”
Type: number | undefined (optional)

Defines an element’s row index or position with respect to the total number of rows within a table, grid, or treegrid.

aria-rowindextext

Section titled “aria-rowindextext”
Type: string | undefined (optional)

Defines a human readable text alternative of aria-rowindex.

aria-rowspan

Section titled “aria-rowspan”
Type: number | undefined (optional)

Defines the number of rows spanned by a cell or gridcell within a table, grid, or treegrid.

aria-selected

Section titled “aria-selected”
Type: Booleanish | undefined (optional)

Indicates the current “selected” state of various widgets.

aria-setsize

Section titled “aria-setsize”
Type: number | undefined (optional)

Defines the number of items in the current set of listitems or treeitems. Not required if all elements in the set are present in the DOM.

aria-sort

Section titled “aria-sort”
Type: "none" | "ascending" | "descending" | "other" | undefined (optional)

Indicates if items in a table or grid are sorted in ascending or descending order.

aria-valuemax

Section titled “aria-valuemax”
Type: number | undefined (optional)

Defines the maximum allowed value for a range widget.

aria-valuemin

Section titled “aria-valuemin”
Type: number | undefined (optional)

Defines the minimum allowed value for a range widget.

aria-valuenow

Section titled “aria-valuenow”
Type: number | undefined (optional)

Defines the current value for a range widget.

aria-valuetext

Section titled “aria-valuetext”
Type: string | undefined (optional)

Defines the human readable text alternative of aria-valuenow for a range widget.

autoCapitalize

Section titled “autoCapitalize”
Type: "off" | "none" | "on" | "sentences" | "words" | "characters" | (string & {}) | undefined (optional)

autoCorrect

Section titled “autoCorrect”
Type: string | undefined (optional)

autoFocus

Section titled “autoFocus”
Type: boolean | undefined (optional)

autoSave

Section titled “autoSave”
Type: string | undefined (optional)

className

Section titled “className”
Type: string | undefined (optional)

color

Section titled “color”
Type: string | undefined (optional)

container

Section titled “container”
Type: Element | ((element: Element) => Element) | null | undefined (optional)

An HTML element, or a function that returns one. It’s used to set the container the Slide is transitioning from.

content

Section titled “content”
Type: string | undefined (optional)

contentEditable

Section titled “contentEditable”
Type: Booleanish | "inherit" | "plaintext-only" | undefined (optional)

contextMenu

Section titled “contextMenu”
Type: string | undefined (optional)

dangerouslySetInnerHTML

Section titled “dangerouslySetInnerHTML”

datatype

Section titled “datatype”
Type: string | undefined (optional)

defaultChecked

Section titled “defaultChecked”
Type: boolean | undefined (optional)

defaultValue

Section titled “defaultValue”
