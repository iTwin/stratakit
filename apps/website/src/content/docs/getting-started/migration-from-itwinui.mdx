This guide provides the necessary steps for migrating from [iTwinUI](https://itwinui.bentley.com/) to StrataKit.

:::note
Migration to StrataKit can be done gradually, since iTwinUI can coexist in the same application by utilizing the [StrataKit theme bridge](https://github.com/iTwin/iTwinUI/wiki/StrataKit-theme-bridge).
:::

## Migration steps

<Steps>

1. **Set up StrataKit**

   Follow the [set up StrataKit guide](/getting-started/develop/) to install the necessary dependencies and set up your project.

2. **Enable the StrataKit theme bridge**

   Pass the StrataKit [**Root**](/components/root) into the `as` prop of the iTwinUI [**ThemeProvider**](https://itwinui.bentley.com/docs/themeprovider) to render a single DOM element.

   ```diff
    <ThemeProvider
      theme={theme}
   +  as={Root}
    >
      {/* … */}
    </ThemeProvider>
   ```

   Specify the `Root` props directly on the `ThemeProvider` component.

   ```diff
    <ThemeProvider
      theme={theme}
      as={Root}
   +  colorScheme={theme}
    >
      {/* … */}
    </ThemeProvider>
   ```

   Finally, activate the `themeBridge` future flag.

   ```diff
    <ThemeProvider
      theme={theme}
      as={Root}
      colorScheme={theme}
   +  future={{ themeBridge: true }} // or future={true}
    >
      {/* … */}
    </ThemeProvider>
   ```

   :::note
   If StrataKit's accent color is not compatible with your existing UI, see [visual transition](#visual-transition).
   :::

3. **Replace `@itwin/itwinui-icons-react` with `@stratakit/icons`**

   Replace the usage of iTwinUI icons from `@itwin/itwinui-icons-react` with their StrataKit counterparts. Refer to the [use StrataKit icons](#use-stratakit-icons) section below for the full icon mapping.

   ```diff
   - import { SvgAdd } from '@itwin/itwinui-icons-react';
   - <SvgAdd />

   + import { Icon } from "@stratakit/mui";
   + import { svgAdd } from "@stratakit/icons/add";
   + <Icon href={svgAdd} />
   ```

   Once all usage of `@itwin/itwinui-icons-react` has been replaced, it is safe to remove the dependency.

   ```console
   npm uninstall @itwin/itwinui-icons-react
   ```

4. **Replace usage of `@itwin/itwinui-react`**

   Replace the usage of components from `@itwin/itwinui-react` with their [StrataKit counterparts](/components/overview/). Some components are provided by `@mui/material`, while others live in `@stratakit/structures`.

   Once all usage of `@itwin/itwinui-react` has been replaced, it is safe to remove the dependency.

   ```console
   npm uninstall @itwin/itwinui-react
   ```

</Steps>

## Visual transition

By default, StrataKit uses its preferred **"aurora"** green [accent color](/components/root/#accent-color). Some legacy applications rely on a blue accent color, especially when parts of the UI are not implemented with up-to-date iTwinUI components. In these cases, the aurora accent color can clash with the existing UI or require significant adjustments to it.

To ease the visual transition, use StrataKit's **"cobalt"** accent color, which is designed for better compatibility with iTwinUI's color palette. Set the `unstable_accentColor` prop on the [**Root**](/components/root) component to apply the accent color to all StrataKit components.

```diff
 <ThemeProvider
   theme={theme}
   as={Root}
   colorScheme={theme}
   future={true}
+  unstable_accentColor="cobalt"
 >
   {/* … */}
 </ThemeProvider>
```

Once the visual transition is complete, remove the `unstable_accentColor` prop to continue using StrataKit's preferred accent color.

### Alert

- Use the `severity` prop to replicate iTwinUI `Alert`'s [`status`](https://itwinui.bentley.com/docs/alert#statuses) prop.
- Set the CSS [`position`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/position) property to `sticky` to replicate iTwinUI `Alert`'s [`sticky`](https://itwinui.bentley.com/docs/alert#sticky-alert) prop.

### Anchor

- Append the `Link` with an [`Icon`](/components/icon/) displaying [`window-popout.svg`](/icons/) to replicate iTwinUI's `Anchor`'s [`external`](https://itwinui.bentley.com/docs/anchor#external-links) prop.
- The [`underline`](https://itwinui.bentley.com/docs/alert#underlines) prop has been purposefully not exposed as a prop and is instead handled by the design system itself.

### Avatar

- Set the CSS [`block-size`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/block-size) and [`inline-size`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/inline-size) properties to replicate iTwinUI `Avatar`'s [`size`](https://itwinui.bentley.com/docs/avatar#sizes) prop.
- Pair with [`Badge`](/components/badge/) to replicate iTwinUI `Avatar`'s [`status`](https://itwinui.bentley.com/docs/avatar#status-indicators) prop.

### AvatarGroup

- Use the [`renderSurplus`](/components/avatargroup/#surplus) prop to replicate iTwinUI `AvatarGroup`'s [overflow](https://itwinui.bentley.com/docs/avatar#overflow).

### Badge

- Use the [`color`](/components/badge/#colors) prop to replicate iTwinUI `Badge`'s [status background colors](https://itwinui.bentley.com/docs/badge#statuses).

### Blockquote

- Use the native [`<blockquote>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/blockquote) element.

### Breadcrumbs

- The [truncation](https://itwinui.bentley.com/docs/breadcrumbs#truncation) feature is not suggested.

### Button

Replace the [`Button` component from `@itwin/itwinui-react`](https://itwinui.bentley.com/docs/button) with the `Button` component from `@mui/material`. See [Button examples](/components/button/) for reference.

- Replace `styleType="cta"` with `color="primary"`.
- Replace `styleType="borderless"` with `variant="text"`.
- Replace `styleType="high-visibility"` with the default button unless it is the main action for a dialog or a page. In that case use `color="primary"`
- `size` and `loading` props require no adjustment.
- In place of `DropDownButton` use a [selectable menu](/components/menu/#selectable)
- In place of `SplitButton` use a `ButtonGroup` to wrap two `Button`s. The first `Button` executes the selected action, the other opens a `Menu` to change the action.
- In place of `IconButton` from `@itwin/itwinui-react` use [`IconButton`](components/iconbutton/) from `@mui/material`.
- In place of `IdeasButton` use a `Button` from `@itwin/itwinui-react` with CSS styling for position.

### ButtonGroup

Replace the [`ButtonGroup` component from `@itwin/itwinui-react`](https://itwinui.bentley.com/docs/buttongroup) with the `ButtonGroup` component from `@mui/material`. See [ButtonGroup examples](/components/buttongroup/) for reference.

- Replace `<ButtonGroup role="toolbar">` with [`Toolbar` from `@stratakit/structures`](/components/toolbar/)
- Instead of `ButtonGroup` and `Input` use `TextField` from `@material/mui` with `startAdornment` or `endAdornment` props.

### Carousel

Use of [Carousel](https://itwinui.bentley.com/docs/carousel) is discouraged. StrataKit does not provide this component.

### Checkbox

Replace the [`Checkbox` component from `@itwin/itwinui-react`](https://itwinui.bentley.com/docs/checkbox) with the `Checkbox` component from `@mui/material`. See [Checkbox examples](/components/checkbox/) for reference.

- `<Checkbox status="negative"/>` for errors can be replaced with`<FormControlLabel error>`, see the [Checkbox error example](/components/checkbox/#error).

### Code

No StrataKit equivalent, use native [`<code>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/code)

### ColorPicker

For basic usage requiring a limited list of colors you can replace `ColorPicker` with a `Select` from `@mui/material`.

For more advanced usage that requires setting arbitrary color values, use `<Input type="color"/>` from `@material/mui`.

### Combobox

Replace [`Combobox` from `@itwin/itwinui-react`](https://itwinui.bentley.com/docs/combobox) with `Autocomplete` from `@mui/material`. See [`Autocomplete` examples](/components/autocomplete/).

### DatePicker

Replace [`DatePicker` from `@itwin/itwinui-react`](https://itwinui.bentley.com/docs/datepicker) with `DatePicker` from `@mui/x-date-pickers`. See [`DatePicker` examples](/components/datepicker/).

- For date range selection replace the single `<DatePicker enableRangeSelect>` with two `DatePickers`, one for the start and one for the end.
- For stand alone usage, use `DateCalendar` from `@mui/x-date-pickers`.
