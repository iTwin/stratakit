Migrating from iTwinUI

Learn how to migrate from iTwinUI to StrataKit

This guide provides the necessary steps for migrating from iTwinUI to StrataKit.

Note

Migration to StrataKit can be done gradually, since iTwinUI can coexist in the same project by utilizing the StrataKit theme bridge.

Migration steps

Section titled “Migration steps”

  1. Set up StrataKit

    Follow the set up StrataKit guide to install the necessary dependencies and set up your project.

  2. Enable the StrataKit theme bridge

    Pass the StrataKit Root into the as prop of the iTwinUI ThemeProvider to render a single DOM element.

    Specify the Root props directly on the ThemeProvider component.

    Finally, activate the themeBridge future flag.

  3. Replace @itwin/itwinui-icons with @stratakit/icons

    Replace the usage of iTwinUI icons from @itwin/itwinui-icons with their StrataKit counterparts. Refer to the use StrataKit icons section below for the icon mapping.

    Once all usage of @itwin/itwinui-icons has been replaced, it is safe to remove the dependency.

  4. Replace usage of @itwin/itwinui-react

    Replace the usage of components from @itwin/itwinui-react with their StrataKit counterparts.

    Some components are provided by @mui/material.

    Others live in @stratakit/structures.

    Once all usage of @itwin/itwinui-react has been replaced, it is safe to remove the dependency.
